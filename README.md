# econometrics-msa-projects
Этот репозиторий содержит мои проекты по эконометрике и многомерному статистическому анализу, в которых я работаю с реальными экономическими данными (урожайность, показатели рынка нефти). С помощью Python (pandas, statsmodels, scipy, seaborn) я строю, оптимизирую и валидирую регрессионные модели, демонстрируя полный цикл работы аналитика: от разведочного анализа и отбора признаков до глубокой статистической диагностики.
В ноутбуках реализован метод наименьших квадратов (OLS) и алгоритмы пошагового отбора переменных (Forward и Backward) для устранения мультиколлинеарности. Особое внимание уделено проверке состоятельности моделей: я провожу тесты Уайта и Голдфельда-Квандта на гетероскедастичность, тест Чоу на структурные сдвиги, RESET-тест Рамсея на спецификацию, а также тесты на линейные ограничения и анализ частных коэффициентов корреляции.
Этот проект показывает мой навык не просто «обучать» модели, а проводить их полноценный статистический аудит и интерпретировать результаты. Сочетание строгой эконометрической теории и практического программирования на Python подтверждает мою готовность извлекать надежные, статистически обоснованные инсайты из сложных данных для решения бизнес-задач.
